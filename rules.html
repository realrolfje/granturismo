Points Breakdown

Each driver completing a race earns points according to final position as described below.

  2. 2nd10 pts
  3. 3rd8 pts
  4. 4th6 pts
  5. 5th4 pts
  6. 6th2 pts
  7. 7th1 pt

Participation bonus

Any driver finishing outside the top 7 still earns 1 point for completing the race. DNS/DNF results yield no points.

Drop round

To account for absences, any driver who has started at least two races discards their single lowest-scoring result. If you only have one start it always counts. The dropped race still appears in the standings breakdown with a red strikethrough so everyone can audit totals.

Tie-breaking Procedure

If two or more drivers tie on points, we apply the following criteria until the tie is broken.

  1. Total Wins

    The driver with the greater number of race victories ranks ahead.

  2. Best Finish

    If wins are equal, we compare the single best finishing position across the season (1st beats 2nd, etc.).

  3. First to Achieve Best Finish

    If wins and best results still match, the driver who recorded that top finish earlier in the season ranks ahead.

  4. Alphabetical Order

    When every metric—including timing of the best finish—remains identical, we fall back to the driver name (alphabetical) to keep the table deterministic.

These rules mirror how the site currently sorts standings, so what you see on the scoreboard always reflects this logic.
